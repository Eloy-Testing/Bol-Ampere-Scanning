# Muisstil secondary account label — visual contract

The authenticated production scanner must identify the fixed secondary account as **Muisstil** in the account-tab row. Bankhoes remains the default selection; selecting Muisstil must retain the existing selected visual state and ready scanner flow without revealing the internal source identity or credentials.

At desktop and mobile widths, the Muisstil label must remain readable beside Bankhoes, retain the existing selected-tab emphasis, and preserve the scan input as the next operational action. The page must not have horizontal overflow, and the production console must have no errors.
